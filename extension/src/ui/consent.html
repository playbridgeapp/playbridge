PlayBridge Video Detector

Allow media detection for casting?

PlayBridge needs to observe media requests on pages you visit so it can find a stream that your TV can play.

What PlayBridge handles

  • Media URLs, the current site, and video metadata.
  • Request and response headers needed to replay a selected stream. These can include Referer, Cookie, or Authorization values.
  • Detected media is kept in browser session storage and cleared when the browser closes, the tab navigates, or you clear it.
  • When you choose Cast, the selected URL and required headers are sent only through native messaging to the PlayBridge desktop app and your chosen TV.

PlayBridge does not send this data to its developers, use it for advertising or analytics, sell it, or build a browsing profile.

Media detection is allowed.

You can change this later from the extension Settings tab. Read the privacy policy.
