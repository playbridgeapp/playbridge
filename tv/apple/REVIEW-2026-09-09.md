# Apple TV review — 2026-09-09

Reviewed the receiver's pairing/command dispatch, connection lifecycle, playlist and history flows, playback teardown, status reporting, VLC proxy, and related UI. This was a source review with focused regression tests and a tvOS build, not a full physical-device certification.

## Findings fixed

| Priority | Finding and trigger | Fix | Main source |
| --- | --- | --- | --- |
| Critical | Once any sender authenticated, the global `isAuthenticated` flag allowed another unauthenticated socket to execute commands. | Authorize each socket against its own credential verifier. | `Network/WebSocketServer.swift`, `Models/PairingCredentialState.swift` |
| High | Forgetting a paired device did not disconnect its existing session. Repeated authentication duplicated the connection in broadcast lists. | Disconnect revoked sessions, check current credential validity, and deduplicate authenticated connections. Re-pairing also revokes the old session. | `Network/WebSocketServer.swift` |
| High | Server stop only closed authenticated sockets. An incomplete pairing could survive and block future pairing; a client could stall indefinitely before reveal. | Track all accepted sockets, clear handshakes/timeouts on stop, enforce a 120-second authentication deadline, and handle WebSocket close frames. | `Network/WebSocketServer.swift` |
| High | VLC's internal proxy listened on all interfaces and could attach stream headers to requests from the LAN. | Bind it to `127.0.0.1`. The player already uses loopback URLs. | `Network/VLCProxyServer.swift` |
| High | A scalar command payload could reach Foundation's JSON object serializer, whose invalid top-level object exception is not caught by Swift `try?`. | Validate the JSON object before serialization. | `Network/WebSocketServer.swift` |
| High | MPV teardown synchronously waited on the player queue from the main thread. A stalled player operation could freeze navigation/shutdown. | Queue destruction after outstanding commands, retain the output layer until destruction, and ignore late end callbacks after teardown. AVPlayer teardown now explicitly stops and releases its item too. | `Player/MPVPlayerView.swift`, `Player/NativePlayerView.swift` |
| Medium | VLC processed the first TCP packet as a complete HTTP request, potentially losing Range headers or parsing a partial request line. | Accumulate a bounded complete header block; reject malformed/unsupported request lines. Normalize query escaping before assigning URLComponents. | `Network/VLCProxyServer.swift` |
| Medium | VLC proxy startup blocked the main thread for up to three seconds and could attempt playback with port zero after failure. | Start asynchronously and only launch playback after the listener is ready; ignore callbacks for dismissed/replaced players. | `Network/VLCProxyServer.swift`, `Player/VLCPlayerView.swift` |
| Medium | Aborting a proxy upstream task could leave the downstream socket open. HLS preview logging also exposed playlist contents in release builds. | Close the downstream connection on abort and make playlist previews debug-only. | `Network/VLCProxyServer.swift` |
| Medium | Replaying an item erased its favorite flag. Deferred history mutations could also execute after a clear operation. | Preserve favorites and perform history load/add/clear in call order. | `Data/HistoryStore.swift` |
| Medium | History replay bypassed session setup, lost the title, and could play a stale queued item. Back from preplay also left the queue intact. | Route history replay through normal single-item playback setup; clear queue and still-watching state when preplay is cancelled. | `UI/Views/LibraryListView.swift`, `ContentView.swift` |
| Medium | Filtering invalid playlist entries shifted the requested start index. Empty playlists reported index zero. Remote jumps omitted history recording. | Map the original start index to the filtered list, use `-1` for an empty queue, and record remote jumps unless `skipHistory` is set. Reject relative/empty playback URLs. | `Network/WebSocketServer.swift`, `Network/ProtocolMapper.swift`, `Data/PlaylistStore.swift` |
| Medium | Unknown or overflowing media timestamps could trap during integer conversion in status messages and time labels. | Use checked conversion for all three players and the controls overlay; reject non-finite AVPlayer/MPV seeks. | `Player/PlaybackTime.swift`, player adapters and controls |
| Low | Reconnecting senders did not receive an empty playlist status and could retain a stale queue. | Always send playlist status during authentication resync. | `Network/WebSocketServer.swift` |

## Validation

- `bash tv/apple/tests/run-receiver-review-checks.sh` — passed. Exercises connection authorization isolation, credential revocation/rotation, disconnection and reset; favorite retention, history reload/clear/limits; invalid and overflowing timestamps.
- `bash tv/apple/tests/run-proxy-review-checks.sh` — passed. Compiles the production Swift proxy and uses real loopback TCP/HTTP connections to test asynchronous startup, fragmented headers, Range and configured header forwarding, and malformed requests. Requires permission to bind loopback sockets in restricted environments.
- `ruby scripts/check-spec.rb` from `protocol/` — passed (75 schemas, 79 references).
- tvOS Debug build — passed with `CODE_SIGNING_ALLOWED=NO`. The signed build could not proceed because no development provisioning profile for the TV bundle identifier is installed. No signing settings were changed.
- `git diff --check` — passed.

## Physical-device follow-up

Test these on Apple TV before release:

1. Pair two phones; forget one while connected and confirm only that phone loses control. Reconnect after background/foreground and server restart.
2. Cancel preplay, open a favorite, and confirm the chosen video/title plays with no old queue. Replay and confirm it remains a favorite.
3. Switch and exit AVPlayer/VLC/MPV during buffering; check responsiveness, audio cleanup, and MPV HDR/display transitions.
4. Cast a playlist with a nonzero starting item, jump from the phone, and confirm `skipHistory` items remain absent from history.
5. Play and seek a header-protected MP4/HLS stream through VLC's proxy, including direct-to-proxy fallback.

The regression tests cover isolated authorization state and local HTTP transport; live protected pairing and decoder/rendering behavior still require device testing. These fixes preserve the existing wire contract and required no major product decision or migration.
